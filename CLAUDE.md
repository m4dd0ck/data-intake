# DataIntake: agent rules

Read `README.md` for how it works, `RUNBOOK.md` for procedures, `TASK.md` for what is open.
Global rules in `~/.claude/CLAUDE.md` apply.

- Public repo: no personal data, account numbers, keys or third-party names in any file. A
  real client's exports never enter the repo; the demo data is synthetic with an answer key.
- Real-time commits only; never backdate or set `GIT_AUTHOR_DATE`. No AI attribution.
- Release steps follow `~/developer/hq/CONVENTIONS.md`; the procedure is in `RUNBOOK.md`.
- The report must stay one HTML file with no scripts or external assets, and every data value
  escaped; the tests enforce it, so a template change that needs an exception is a design
  question for the owner.
